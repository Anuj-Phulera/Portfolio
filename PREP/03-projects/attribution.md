# Attribution policy

## Why this file exists

VERDE's README describes a custom PCB, a buck converter, soldering and a physical build. Those are **Aarav Choudhary's** work, per the project's own team section. A portfolio that lets a reader assume otherwise is not ambitious; it is dishonest, and it fails the first technical question.

## Rules

1. **Every project page states who built what**, in one sentence, before any feature list.
2. **Hardware is never implied to be solo** on VERDE. The board, power delivery and physical build belong to Aarav.
3. **Team projects name the team**, or state that individual contributions are not yet itemised.
4. **AI assistance is disclosed where it materially shaped the work.** Several recent repositories contain merged `arena/*` pull requests. That does not diminish the work; hiding it would.
5. **Personal narrative requires consent** from the people it describes. RAKSHABANDHAN is about a real person.

## Approved attribution sentences

**VERDE**
> Built with Aarav Choudhary. I wrote the software, the cloud pipeline, the vision model and this site. Aarav designed the board, the power delivery and the physical build.

**SKILLVERSE**
> A four-person team project. The repository does not itemise individual contributions, so I will not claim more than my share.

**Everything else**
> Sole author, with AI assistance for implementation, under my direction.

## The test

Read the attribution sentence aloud to the collaborator it describes. If they would object, it is wrong.
