# Endings — three candidates

An ending has one job: convert attention into a next step, without begging.

## A. The Ledger — "next entry"

A single page, mostly empty. A dated line:

> **ENTRY 010 — UNWRITTEN.**
> If you want to see what goes here, write to me.

Below it: one email address, one repository link, one line of context (*"I reply to everything that is not a recruiter template."* — only if true). No contact form, no calendar embed, no social icon row.

**Effect:** the visitor is left with an open slot, which is the most honest possible call to action for someone mid-ascent.
**Risk:** may read as coy; needs a concrete, easy action.

## B. Threshold — "the door"

The final room is a doorway with light beyond it. The camera moves toward it as the reader scrolls the last 40%, then stops — the door does not open. One line:

> *The next room is being built.*

Then the contents panel returns, with everything the visitor might need: work, writing, contact, source. The refusal to show what is beyond the door is the invitation.

**Effect:** memorable, emotionally congruent with the rest.
**Risk:** withholding can frustrate; must be followed immediately by a real contact path.

## C. Instrument — "the object under the cloth"

The last station is a cloth-covered object. It can be lifted. Underneath: a single machined plate engraved with the next thing being built — a name, a constraint, a date. Beside it, three actions: *Follow*, *Write*, *See the source of this site.*

**Effect:** the visitor physically uncovers the future; the gesture is the message.
**Risk:** if the "next thing" is vague, the reveal is empty. It must be a real project with a real sentence.

## Shared rules

1. **No "let's work together" without a specific reason to.**
2. **One primary action.** Email, most likely. Everything else is secondary.
3. **Show the site's own source.** A portfolio that asks to be trusted should be inspectable.
4. **No confetti, no "thanks for scrolling," no fake availability badge.**
5. **The ending must work with JavaScript disabled.** Plain links, plain text.
6. **Remember the visitor's time.** The ending arrives when the argument is complete, not after a fixed number of sections.

## The last impression test

Close the tab immediately after the ending. What remains is the memory. If it is "that was a nice website," the ending failed. If it is a sentence the visitor could repeat to a friend — *"he has a project that changes its own layout and proves it with tests"* — it worked.
