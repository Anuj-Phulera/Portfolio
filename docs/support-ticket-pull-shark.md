# Draft: GitHub Support ticket — Pull Shark not awarded

Paste this at <https://support.github.com/contact>. It asks for a badge to be
correctly calculated. It does not ask for a badge to be granted.

---

**Subject:** Pull Shark not awarded at 16 merged pull requests

**Body:**

My account (Anuj-Phulera) has 16 merged pull requests into the default branch of
a public repository, which is the Bronze threshold for Pull Shark. The badge has
not appeared. It has been longer than the usual processing delay.

Details:

- Repository: `Anuj-Phulera/Portfolio` (public)
- Merged pull requests: 16, all into `main`, the default branch
- All were authored by this account and merged by this account
- Evidence: `https://github.com/Anuj-Phulera/Portfolio/pulls?q=is%3Apr+is%3Amerged`
  returns 16
- I also merged a pull request containing a commit with a `Co-authored-by:`
  trailer, and Pair Extraordinaire did not appear either.

I am aware of open reports from August and September 2026 describing the same
behaviour: <https://github.com/orgs/community/discussions/206691> and
<https://github.com/orgs/community/discussions/207838>. In the second thread the
reporter says the badge appeared after contacting Support.

One thing that may be relevant: on 2026-10-24 this repository received a block
of roughly 230 commits that were made to fill the contribution graph rather than
to change the project. The contribution graph did not credit them all, and
achievement awarding also appears to have stopped around that time. If that
activity caused a flag on the account, I would rather know, and I would rather
have the flag than the badge.

Could you confirm whether the merged pull requests qualify, and whether the
account is subject to any restriction that would prevent achievements from being
awarded?

Thank you.

## What this ticket does not do

It does not ask GitHub to grant anything. The merged pull requests either qualify
or they do not, and Support can see which. If the answer is that the backfill on
24 October put the account under a restriction, that is the more useful answer,
because it explains the frozen contribution graph as well.
