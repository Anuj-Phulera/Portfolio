# Content policy

What this site will and will not publish. Derived from `PREP/09-assets/` and the
claims ledger; enforced in code by `docs/decisions/0002-claims-gate-at-build.md`.

## Publishable

- Counts read from source: routes, nodes, edges, lines, files.
- File paths, and the fact that a verification command exists.
- Technical decisions that are visible in a repository.
- Corrections of the author's own earlier claims.

## Not publishable

- Anything marked `do-not-publish` or `internal-only` in the ledger.
- Anything about a third party without their consent.
- User numbers, revenue, awards, adoption. There are none, so there is nothing
  to say and nothing is implied.
- Accessibility conformance. No audit has been run on any project, including
  this one; the site describes what it does, not what it conforms to.
- Performance on devices it has not been tested on.

## Withheld

RAKSHABANDHAN is built and private. The entry exists, states that consent has
not been given, and describes only the engineering and the design principle the
project produced. No names, dates, places or content from the site appear here.

## Attribution

VERDE is a two-person build. The entry says which half is whose, in the same
block as the project's name, because attribution that appears at the bottom is
attribution that gets removed first.

SKILLVERSE is a team project whose per-person contribution is not recorded in
the repository. The entry says that plainly rather than guessing, and treats the
missing record as the finding.

## Tone

No adjectives about the author. No superlatives about the work. Numbers where
numbers exist; `UNVERIFIED` where they do not.
